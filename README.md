## 双 ISP 到底在验什么，四步能筛掉大部分假家宽

双 ISP 的判定要看两个维度同时成立：Company 类型显示为 ISP，ASN 类型也显示为 ISP。两个都满足才算完整证据，只满足一个的，很可能是广播段做出来的假象。行业里的实际情况是，市面上九成以上号称家宽的 VPS，只是检测工具显示双 ISP 类型，IP 本身还是广播来的。

怎么筛：

1. **多工具交叉验证**。单一检测工具的结果容易被针对优化，换两三个数据库比对。
2. **查 IP 注册信息和路由轨迹**。真住宅 IP 的归属链路能一路对应到当地运营商的宽带网络，而不是某个数据中心段。
3. **看商家怎么拿到资源**。自己拉当地宽带组建服务器的，真实性最高；只买了几段广播 IP 的，说不清上游。
4. **在真实业务环境里试**。假住宅 IP 在风控严格的平台上一用就露馅，这一条比任何检测工具都准。

SixtyNet 这边的第三方记录：2025 年 10 月的一篇测评以 Cox Communications 段的产品为样本，ipinfo 显示双 ISP 属性，多个数据库判断为原生美国 IP、家宽属性、流媒体解锁全绿。这是单点样本，不代表你现在买到的每一段 IP 都一样，但至少说明它的住宅资源不是纯广播段包装出来的。

## 国内访问：官方屏蔽了 PING，只能看路由

SixtyNet 官方屏蔽了 ICMP，也屏蔽了 80 和 443，所以拿不到 ping 延迟数据。这不是测评方偷懒，是产品本身不让你测。判断线路只能看路由。

测评记录的去程：电信走 CN2 直连洛杉矶，联通直连洛杉矶节点后接 GTT 再接 Cox，移动直连洛杉矶节点。回程：电信走 CN2，联通走 AS10099 + AS9929，移动强制走电信 CN2 回国。

这个组合放在美西住宅 VPS 里是偏上的。作为参照系，几款国内商家同类产品的全国三网 ping 大致落在 174–215ms 区间：有的走 AS9929 回程能做到 174ms 但带宽只有 30–50Mbps，有的三网 196ms 但实测上传能跑到 439Mbps。这些数字口径是“全国三网 ping”，跟“本地 ping”不能混着比。

需要单独提醒的是移动宽带用户。同类型产品里有移动绕路香港、东京、圣何塞才到美西的例子，丢包率能到 10%–30%。SixtyNet 的路由记录里移动去程是直连、回程走 CN2，看起来没这个问题，但既然测不到 ping，实际丢包只能自己跑一遍。

## FAQ

**双 ISP 和“原生 IP”有什么区别？**
原生 IP 说的是 IP 注册地和机房所在地一致，不涉及住宅属性。双 ISP 说的是这个 IP 同时被两个互联网服务商注册，在风控数据库里被归为住宅而非数据中心。建站用原生 IP 就够，账号运营才需要住宅双 ISP。同品牌同配置下，住宅双 ISP 线通常比原生 IP 线贵 40% 左右。

**住宅 IP 能保证不封号吗？**
不能。住宅 IP 只是降低风控触发概率，账号行为、设备指纹、操作频率同样在被判定。任何承诺“用了就不封”的说法都不成立。

**5TB 月流量对账号运营够不够？**
够。账号类业务月消耗很少超过 500GB，5TB 意味着你有十倍余量。真跑满 5TB 的，通常是素材上传下载或直播推流，那要重新算带宽而不是流量。

**30Mbps 带宽能干什么？**
远程桌面、网页操作、社媒发布都够。不够的是大文件上传、高清直播推流、多路并发。SixtyNet 的住宅线起步就是 2G 优质网络（官方页面标注），带宽不是它的短板，流量档位才是你要算的。

**为什么家宽 VPS 延迟比机房高？**
家宽走的是住宅网络基础设施，路径比机房专线长，170–250ms 是常态。用 AS9929 优化回程能压到 180–210ms，在美国家宽里已属第一梯队。对延迟极敏感的业务，常规做法是配香港或日本中转。

**IP 被墙了能换吗？**
官网没有公开换 IP 政策。这类事只能下单前问客服，别默认可以免费换。
